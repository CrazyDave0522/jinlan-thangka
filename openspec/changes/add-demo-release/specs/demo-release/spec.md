## ADDED Requirements

### Requirement: Deployable validated demo

The system SHALL provide a Vercel-hosted demo whose integrated text and image conversation flows, retrieval, answer generation, and source inspection have been verified against agreed acceptance samples.

#### Scenario: Run the deployed demo acceptance flow

- **WHEN** a reviewer exercises agreed text and image questions in the deployed demo
- **THEN** the reviewer can complete submission, retrieval, answer viewing, and source inspection, with uncertain results and service failures represented appropriately.
