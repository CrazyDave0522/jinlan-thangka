The clipboard concurrency observation is a design risk derived from the initial ownership rules, not a reproduced claim about every browser's completion order. The [W3C Clipboard API working draft](https://www.w3.org/TR/2026/WD-clipboard-apis-20260624/#dom-clipboard-writetext) defines promise-based `writeText` without an abort parameter. The proposed five-second UI threshold is an application choice; it cannot cancel or retract a previously issued write or guarantee ordering against native/manual copying outside the app.

## Scope Decisions Retained

- Existing `SourceCitation` returns title/source identity/link identity/scope/locator. Author/year/publisher/URL, server-only catalogue notes and full source documents are not delivered to this UI; no metadata expansion or source browsing is included. Missing fields are not inferred. If full bibliographic cards or source-document access are later requested, their server projection, validation and acceptance must be specified explicitly.
- Observation/comparison details use already-delivered data, add no provider/database/Storage calls and do not expose curated pixels. Model-reported reading confidence is not independent archive verification. Unrelated historical observations are excluded.
- Record-only/unscoped/disputed evidence, candidate/insufficient states and empty archive behavior remain first-class. No real dataset, curated grant, funded evaluation or deployment is needed to implement these UI contracts.
- All source/copy/controller behavior tests remain implementation tasks. Approval is still separate from this omission review; no business code, wire schema or environment setting has changed.

## Second Implementation Recheck — 2026-10-17

The owner's next review request focused on interactions among source navigation, manual-copy dismissal, pending writes, background responses and short viewports. Source-link fidelity, answer-local E/R targets and export/context boundaries showed no additional data defect. A browser regression reproduced one focus-visibility defect in two dismissal paths at the supported 844×390 landscape size:

- After selecting and dismissing the old answer's manual-copy text, the copy button received focus at y=-141 while the visible conversation region started at y=57.
- Activating the source disclosure while DOM focus remained on E64 collapsed the long panel and focused its trigger at y=-401. This exercises disclosure activation without first moving DOM focus; an ordinary pointer click scrolls the trigger into view before closing and had concealed the defect. This synthetic activation is not native screen-reader acceptance.

Both controls already regained DOM focus, but `preventScroll` left them outside the conversation viewport. The explicit dismissal paths now scroll the owning control to the nearest visible position. Source restoration waits for the Base UI panel's actual hidden commit through its supported render composition; scrolling before the internal closing stage completes loses the intended focus-ring clearance. Theme-scale scroll margins on copy/disclosure controls, citation markers and evidence targets preserve clearance for their focus rings. These changes do not add autofocus to clipboard timers or promise settlements, or resume automatic bottom-follow: dismissal remains explicit reading intent.

Screenshot review also exposed stale recovery instructions pointing to text after it had been dismissed. Closed failure/waiting/busy feedback now describes explicit retry or reopening instead of selecting hidden content; component regressions cover each state without changing write arbitration.

The two browser regressions assert focus, full control visibility with scroll-margin clearance, composer/footer reachability and independent composer focus after dismissal. Keyboard dismissal and activation with DOM focus inside the panel are both covered. They use the existing maximum-evidence harness and synthetic clipboard failure. Final suite/build/spec results are recorded in verification.md; owner acceptance and real-data/deployment limits remain unchanged.
